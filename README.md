# Mangrove IT Website

A modern, interactive website for Mangrove IT built with Next.js, Tailwind CSS, MongoDB, and Node.js.

## Prerequisites

- Node.js (v18 or later)
- npm (v9 or later)
- MongoDB (local or Atlas)

## Installation

1. Install Node.js from [https://nodejs.org/](https://nodejs.org/)
2. Clone this repository
3. Install dependencies:
   ```bash
   npm install
   ```
4. Create a `.env.local` file in the root directory with your MongoDB connection string:
   ```
   MONGODB_URI=your_mongodb_connection_string
   ```

## Development

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- Modern, responsive design
- Interactive animations using Framer Motion
- Service showcase with icons
- Contact form
- MongoDB integration for data persistence
- SEO optimized
